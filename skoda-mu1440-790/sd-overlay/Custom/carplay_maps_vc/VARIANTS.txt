MHI2-Carplay-Maps 790 v2 - варианты для Škoda MU1440 / приборки 790 (на основе omonob 2.0.1)

Сторона карточки выбирается в магнитоле: App-Connect -> Virtual Cockpit settings ->
Navigation card: Left / Right / Center / Off.
omonob 2.0.1 сам выбирает одну из 5 зон по стороне карточки и по тому, ведёт ли CarPlay
по маршруту. Вариант = набор из 5 зон + время прибытия + частота кадров.

Зона = область видео приборки 1010x376 (X слева направо, Y сверху вниз), внутри которой
навигатор ставит курсор, карточку и полосу прибытия. Карта всегда на весь экран.
Без маршрута у Left, Right и Off зона общая; у Center зона одна всегда.
Время прибытия (showETA=yes) - только при карточке Left и Right.

Install AID 10.5 ставит вариант YANDEX-2026. Всё остальное (логи, видеобуфер, страница
Virtual Cockpit settings, Mirroring) - как в omonob 2.0.1 без изменений.
Show - вариант, сторона карточки и заполненность RAM-диска в % (при работающей
карте около 80% - это видеобуфер 16 МБ, нормально).

Перед Install выньте кабель CarPlay. После любой кнопки дождаться ..._OK,
затем полная перезагрузка (держать кнопку питания ~10 с).
